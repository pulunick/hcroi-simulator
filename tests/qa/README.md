# tests/qa — Playwright 브라우저 QA

화면을 실제로 띄워 회귀를 잡는 재검증 스크립트. 단위테스트(`src/lib/hcroi/*.test.ts`)가 못 잡는
레이아웃 깨짐·가로 스크롤·색상·왕복(엑셀/PDF)·브랜치 분기(main ↔ product/commercial)를 본다.
커밋 전 필수는 아니다(`CLAUDE.md` 테스트 절 참고).

## 사전 조건

- dev 서버가 `http://127.0.0.1:5173` 에 떠 있어야 한다: `npm run dev`
- 로컬에 **Google Chrome** 이 설치되어 있어야 한다(플레이라이트 번들 브라우저는 받지 않고
  `channel: 'chrome'` 로 그 Chrome 을 그대로 쓴다). 없으면 스크립트가 안내를 찍고 종료한다.

## 실행법

```bash
npm run qa        # sweep → items → baseline → branch → dark (5개 순서대로, 하나라도 실패하면 중단)
npm run qa:site   # 공개판(product/commercial) 전용 — main 트리에서는 "공개판 아님 — 건너뜀"
npm run qa:pdf    # 결산서 PDF 카드 검증 — PDF1=경로 PDF2=경로 로 실행, 둘 다 없으면 건너뜀
```

각 스크립트는 끝에 PASS/FAIL 표를 찍고, 하나라도 FAIL 이면 종료 코드 1 을 낸다.

## 파일

| 파일           | 내용                                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------------------- |
| `lib.mjs`      | 공통 유틸(BASE·OUT·로컬 Chrome 실행·결과 표·`SITE_ENABLED` 읽기)                                              |
| `sweep.mjs`    | 7화면 스윕 — 탭 제목·h1·헤더 링크·워드마크·표 폭(모바일은 overflow 래퍼 있으면 허용)·가로 초과·콘솔/HTTP 오류 |
| `items.mjs`    | 개별 QA 항목 — 기간 추가·복사됨 칩·인원 0·오류 레코드·합산 없음·전체 삭제·데이터 지우기 후 리포트             |
| `baseline.mjs` | 기준선 3종 + 회귀 스팟                                                                                        |
| `branch.mjs`   | 브랜치 분기(`SITE_ENABLED` 자동 감지) · `?start=` 3종 · 증감 색 · 다크 입력칸                                 |
| `pdf.mjs`      | 결산서 PDF 카드의 기간 구간 판정(`qa:pdf`)                                                                    |
| `site.mjs`     | 공개판(product/commercial) 전용 — 첫 방문 `/`→`/intro` 리다이렉트·랜딩 CTA·모바일 랜딩(`qa:site`)             |
| `dark.mjs`     | 다크 모드 스윕                                                                                                |

## 기준선 3종의 의미 (`baseline.mjs`)

1. **리포트 A4 정확히 1장** — `/report` 를 PDF 로 찍었을 때 페이지가 딱 1장이어야 한다(넘치면 인쇄 레이아웃 회귀).
2. **엑셀 내보내기 → 전체 삭제 → 가져오기 왕복** — 내보낸 엑셀을 그대로 다시 가져왔을 때 6행 이상, 오류 0행이어야 한다.
3. **390px 가로 스크롤 0** — 가장 좁은 모바일 폭에서 어떤 화면도 가로로 스크롤되면 안 된다.

## 산출물

`tests/qa/out/`(기본값)에 스크린샷·`b-report.pdf`·`rt.xlsx` 등이 쌓인다. `.gitignore` 처리되어 있다.

## 주의

**회사명·실제 재무 수치·실 PDF 는 절대 커밋하지 않는다.** `PDF1`/`PDF2` 로 넘기는 결산서 PDF 는 로컬
경로만 참조하고 저장소에 넣지 않는다. `pdf.mjs` 는 출력에 구간 라벨(예: "3개월"·"누적")과 PASS/FAIL
만 남기도록 만들어져 있다 — 회사명·금액·인원 수치를 콘솔에 찍는 코드를 새로 추가하지 말 것.
