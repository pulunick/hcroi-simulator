# HCROI 도구 2차 확인 요청 — 직접 써 보신 뒤 회신받을 항목

> 2026-09-09. 1차 회신(18문항, 2026-09-03)으로 확정된 요구는 모두 반영했다(분기·월 단위와 자동 합산 · 인건비 4항목 · 임직원 수 산정 기준 · 천원/배수 표기).
> 남은 기능(부서별 · 동종업계 · 변동비)은 담당자 확인 없이 만들면 재작업 위험이 커서, 담당자가 직접 써 본 뒤 아래 항목을 회신받는다.
> **이 도구는 인사담당자 개인 소장용이다** — 전사 관리 시스템이 아니며 배포·권한·감사 요구는 없다. 이직해도 계속 쓰고 필요하면 여러 회사에 보여 주는 형태(2026-09-09 확인).
> 전달물: 배포 링크, [샘플 엑셀](../samples/hcroi-sample-3y-quarterly.xlsx)(가상 회사 3개년 분기 12행), [사용 설명서](../user-guide.md)(8장 "결산서에서 값 옮기기"), 공유용 질문지(아티팩트 — 항목별 답변칸 → 답변 모으기 → 복사, 1차와 같은 방식).

## 하는 순서 (담당자에게 안내)

1. 데이터 관리 → 엑셀 가져오기로 샘플 엑셀을 올려 본다. 분기 4개에서 연간이 합산되는 것을 본다.
2. 엑셀 템플릿을 받아 자사 결산 값을 넣어 본다. 천원·누계면 `조직 정보` 시트 두 칸만 맞춘다.
3. 대시보드·시뮬레이터를 훑고 아래 항목에 답해 복사해 보낸다.

## 1. 동종업계 비교 (회신 14번)

요청은 "결산서 업로드 → 평균 계산". 실측: PDF 표의 숫자가 다른 행에 붙어 자동 파싱은 틀린 값을 섞는다 → 수기 입력이 정확.

- 1-1 입력 방식: A 엑셀 수기(회사·기간·매출·영업이익·인건비·인원) / B DART API 자동(상장사만, 서버 1개) / C 우선 A, 반복되면 B
- 1-2 8개사 전부 상장사인지, 회사명
- 1-3 비교 지표: A HCROI 만 / B + 인당 매출·인당 인건비·인건비율
- 1-4 비교 기준 기간: 연간 / 분기

## 2. 부서별 HCROI (회신 9·10번)

확정: 본부–팀 2단계, 매출 없는 부서는 인건비 비중으로 배부.

- 2-1 부서별 인건비·인원 표의 모양(본부·팀이 열/행), 주기(분기/연). 엑셀 한 장 첨부 요청
- 2-2 매출 부서의 영업이익: A 직접 입력 / B 전부 인건비 비중 배부
- 2-3 조직 개편 시 옛 기간 부서명은 당시 이름 그대로?
- 2-4 부서별 인원 기준이 전사와 같은지(기간 평균 · 정규직만)

## 3. 변동비 (회신 16번)

현재: 시뮬레이터 `고급 가정 → 변동비 비율` 에 % 직접 입력. 결산서 자동 읽기는 1번과 같은 이유로 어렵다.

- 3-1 변동비로 보는 항목: A 매출원가 전체 / B 재료비·외주비만 / C 판관비 일부 포함 / 그 외
- 3-2 분기마다 % 하나 계산해 넣는 방식이면 충분한가 (기간별 저장 칸만 추가)
- 3-3 시나리오가 쓸 비율: A 기준 기간 실제 비율 / B 목표 비율 별도 입력

## 4. 엑셀 양식 (2026-09-09 추가)

현재: 세로형(행 = 기간). 기간 드롭다운·검증 열·금액 단위·누계 옵션 있음.

- 4-1 결산 시트 방향: A 세로형(지금과 같음) / B 가로형(열 = 기간) — B 면 시트 첨부 요청, 가로형 템플릿 추가 여부 결정
- 4-2 결산서 금액 단위(원/천원/백만원), 분기 손익이 누계인지 그 분기 값인지 → 템플릿 기본값을 맞춘다

## 5. 써 보고 느낀 것 (자유)

- 5-1 막힌 곳, 이상하게 나온 숫자(화면·값)
- 5-2 가장 먼저 필요한 것 하나: 부서별 / 동종업계 / 변동비 / 인건비 예산 총액에서 인원·인상률 역산 / 그 외

## 회신 받은 뒤

- 1·2·3 답에 따라 `docs/plans/departments.md` 계획서 → ⑤ 부서별 → ⑥ 동종업계 순서 확정.
- 4-2 답으로 템플릿 `조직 정보` 기본값(단위·누계)을 바꾼다. 4-1 이 B 면 가로형 템플릿 계획 추가.
- 5-2 가 "예산 역산"이면 시뮬레이터에 인건비 총액 입력 → 허용 인원·인상률 역산 모드를 계획한다.
