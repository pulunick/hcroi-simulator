# HCROI 도구 2차 확인 요청 — 직접 써 보신 뒤 확인할 4가지

> 2026-09-09. 1차 회신(18문항, 2026-09-03)으로 확정된 요구는 모두 반영했다(분기 단위 · 인건비 4항목 · 임직원 수 산정 기준 · 천원/배수 표기).
> 남은 두 기능(부서별 · 동종업계)과 변동비는 담당자 확인 없이 만들면 재작업 위험이 커서, 담당자가 직접 써 본 뒤 아래 4가지를 회신받는다.
> **이 도구는 인사담당자 개인 소장용이다** — 전사 관리 시스템이 아니며 배포·권한·감사 요구는 없다(2026-09-09 확인).
> 전달물: 배포 링크, [샘플 엑셀](../samples/hcroi-sample-3y-quarterly.xlsx)(가상 회사 3개년 분기), [사용 설명서 8장](../user-guide.md#8-결산서에서-값-옮기기).

## 1. 동종업계 비교 — 입력 방식 (회신 14번)

**요청하신 것**: 동종업계 결산서를 올리면 평균을 계산.
**실측 결과**: 결산서 PDF 는 텍스트는 뽑히지만 **표의 숫자가 다른 행에 붙는 경우가 있어**(영업수익 행에 영업이익 숫자가 붙는 식) 자동으로 읽으면 틀린 값이 섞인다. 사람이 옮기는 편이 정확하다.

**그래서 확인할 것**

- 8개사 × 분기마다 회사·기간·매출액·영업이익·인건비·인원 6칸을 **엑셀에 손으로 넣는 방식**이 감당 가능한가?
- 아니면 처음부터 **DART 공시 API 로 자동 수집**(회사 코드만 넣으면 분기 재무제표·직원 수를 받아옴)을 원하는가? 이 경우 서버 1개가 필요하고 상장사만 가능하다.
- 비교 대상 8개사는 전부 상장사인가? (비상장이면 API 로 못 받고 수기뿐)
- 비교 지표는 HCROI 하나면 되는가, 인당 매출·인당 인건비·인건비율도 같이 보는가?

## 2. 부서별 HCROI — 데이터 형태 (회신 9·10번)

**확정된 것**: 본부–팀 2단계, 매출 없는 부서에는 **인건비 비중**으로 전사 영업이익을 배부.

**그래서 확인할 것**

- 부서별 인건비·인원이 지금 **어떤 표로** 있는가? (엑셀 한 장 샘플을 보여 주시면 입력 화면을 그 모양에 맞춘다) — 분기마다 있는가, 연 1회인가?
- 매출이 잡히는 부서(사업본부 등)는 **그 부서의 영업이익을 직접 넣을** 수 있는가, 아니면 전 부서를 인건비 비중으로 일괄 배부하면 되는가?
- 조직 개편으로 팀이 생기고 없어질 때, 옛 기간의 부서 이름은 그대로 두면 되는가? (이력 별도 관리라고 하셨으니 "그 기간에 있던 이름 그대로"로 가정)
- 부서별 인원도 전사와 같은 산정 기준(기간 평균 · 정규직만)인가?

## 3. 변동비 — 결산서에서 무엇을 가져오나 (회신 16번)

**현재**: 시뮬레이터 `고급 가정 → 변동비 비율` 에 % 하나를 직접 넣는다. 결산서 자동 읽기는 1번과 같은 이유로 어렵다.

**그래서 확인할 것**

- 결산서에서 **어느 항목을 변동비로** 보는가? (매출원가 전체? 재료비·외주비만? 판관비 중 일부?)
- 분기마다 그 값을 사람이 한 번 계산해 %로 넣는 방식이면 충분한가? 그렇다면 지금 화면으로 이미 가능하고, 기간별로 변동비 비율을 **저장**해 두는 칸만 추가하면 된다.
- "변동비 비율이 크게 변하는 시점"이라고 하셨는데, 시나리오는 **기준 기간의 비율**을 쓰면 되는가, 아니면 목표 비율을 따로 넣고 싶은가?

## 4. 엑셀 양식 — 세로형이면 되는가 (2026-09-09 추가)

**현재**: 한 행 = 한 기간(세로형). 기간 드롭다운·검증 열·금액 단위·누계 옵션까지 넣어 결산서 값을 그대로 붙일 수 있게 했다.

**그래서 확인할 것**

- 지금 갖고 계신 결산 시트가 "열 = 기간, 행 = 항목"(가로형)이면 붙여 넣을 때 방향을 바꿔야 한다. 그 시트 한 장을 보여 주시면 가로형 템플릿을 추가할지 정한다.
- 결산서 금액 단위(천원?)와 누계 여부를 확인한다 — 조직 정보 시트의 두 칸 기본값을 그쪽에 맞춘다.

## 써 보실 때 권장 순서

1. 대시보드 — 샘플로 화면 구성 → 조회 기간(분기) 전환 → 전기·전년 동기 비교
2. 데이터 관리 — 금액 단위(천원) · 임직원 수 산정 기준 · 샘플 엑셀 가져오기(미리보기 → 미분류 경고 → 반영) · 분기 4개에서 연간이 합산되는 것 · 월 추가
3. 시뮬레이터 — 기준 분기 선택, A/B 비교, 변동비 비율 슬라이더(3번 질문으로 연결)
4. 위 4가지 질문에 회신 (엑셀 시트 샘플이 있으면 함께)
