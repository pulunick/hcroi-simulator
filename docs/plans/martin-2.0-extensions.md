2026-09-03 전 쪽 검토 완료. 아래는 원문을 다시 열지 않아도 되도록 옮겨 적은 요약이다.

## 1. 문서가 정의하는 3대 확장

### (1) 기간별 세분화 (Time Horizon)

- 연간 / 분기(Q1–Q4) / 월별(M1–M12) 단위 입력·분석
- 기간 계수 N(연=1, 분기=4, 월=12) 로 **연율화**: `OP_annualized = OP_period × N`, `Cost_annualized = Cost_period × N`
- **HCROI 는 동일 기간 기준 비율이라 연율화 후에도 수치가 같다** (원문 명시)
- 단기 계절성 반영, 누적(YTD) vs 단기 실적 가변 비교

### (2) 부서별 HCROI (Departmental)

- **Profit Center**(영업/사업부): `HCROI_dept = (부서 직접 영업이익 + 부서 인건비) / 부서 인건비`
- **Cost/Investment Center**(R&D/경영지원): 전사 영업이익을 **배부율 α**(인원 비중 **또는** 인건비 비중)로 배부 후 동일 산식 — _둘 중 무엇을 쓸지는 원문에도 택일로 남아 있음 → 결정 필요_
- `HCVA_dept = 부서 기여 부가가치 / 부서 임직원 수`
- 부서별 인건비 비중·생산성 기여도 매트릭스 제공

### (3) 재무제표 결산 보고서 자동 파싱 (OCR/Parsing Engine)

업로드(PDF/Excel/이미지) → 자동 매핑:

| 항목         | 출처 / 계정 과목                        | 추출 규칙                                                               |
| ------------ | --------------------------------------- | ----------------------------------------------------------------------- |
| 매출액       | 손익계산서: 매출액·수익(Sales/Revenue)  | 단일 수치 (영업수익 포함)                                               |
| 영업비용     | 손익계산서: 매출원가 + 판매비와관리비   | 검증식 `OPEX = Rev − OP` 수행                                           |
| 영업이익     | 손익계산서: 영업이익                    | 항목 직접 추출                                                          |
| 총 인건비    | 매출원가 명세서 & 판관비 주석           | **급여 + 제수당 + 퇴직급여 + 법정복리후생비 + 복리후생비 + 교육훈련비** |
| 총 임직원 수 | 사업보고서 [임직원 현황] 또는 결산 주석 | 기말 인원 또는 기간 평균(FTE)                                           |

- 정합성 검증(매출 − 영업비용 = 영업이익), 누락 시 사용자에게 확인 요청

### 그 외 쪽 내용

- 5·6쪽: 에이전트 시스템 프롬프트 전문 (역할 정의 / 수식 / 부서 산출 규격 / 파싱 지침 / 시뮬레이션·응답 규칙)
- 7쪽 UI 와이어프레임: 상단 컨트롤(기간·부서 드롭다운, 파일 드래그앤드롭) · KPI 카드 · 기간별 추이 라인 · 부서별 Grouped Bar · 시뮬레이터 슬라이더 · AI 리포트
- 8쪽 케이스 스터디: 영업본부 30명/24억/20억 → **1.83 우수**, R&D 40명/36억/12억(배부) → **1.33 보통**, 경영지원 10명/8억/3.2억(배부) → **1.40 보통**, 전사 80명/68억/35.2억 → **1.52 우수**
- 9쪽 로드맵: STEP1 ERP/HRIS 연동 + PDF 파서 → STEP2 에이전트 프롬프트 이식 → STEP3 기간/부서 필터·시나리오 검증 후 배포

## 2. 반영 완료 (2026-09-03)

- **등급 3단계 전환**: 원문 케이스 스터디가 1.33·1.40 을 "보통"으로 표기 → 우리가 임의로 정의했던 1.3–1.5 "양호" 구간을 폐지하고 보통에 통합. `HCROI_THRESHOLDS = { warning: 1.0, excellent: 1.5 }`, `HcroiGrade` 에서 `fair` 제거. 수식·배지·인사이트·기준선·가이드표·엑셀 산식 시트·spec §3 전부 반영.
- 핵심 수식·인건비 6항목 정의는 기존 구현과 **일치** (변경 없음).

## 4. 원문을 다시 읽어야 할 때

이미지 PDF 라 `Read` 로 한 번에 못 읽는다(1.7MB > 256KB 제한). 쪽 단위로 분할 후 개별 Read:

```python
from pypdf import PdfReader, PdfWriter   # pip install pypdf
r = PdfReader(원본); [PdfWriter().add_page(p) for p in r.pages]  # 쪽별 저장 후 Read
```
