## 2. 기획서 문구를 해석해서 정한 것 (원문 확인 시 재검토 대상)

1. **"HCROI(%)"** → 배수 × 100 으로 해석, 화면은 배수 1차 · % 보조. 기획서가 %를 1차 표기로 요구했다면 `format.ts` 표기만 바꾸면 됨(계산 불변).
2. **1.3~1.5 구간** → ~~"양호" 로 정의~~ **해결(2026-09-03)**: 확장 지침(Martin 2.0)에 따라 보통에 통합, 3등급 체계로 변경.
3. **"응답규칙"(인사이트)** → 규칙 기반으로 구현. LLM 서술은 Phase 2 (그때 규칙 산출치를 프롬프트 근거로 전달).
4. **비인건비 처리** → 기획서에 명시가 없어 "기본 고정비 + 변동비 비율 옵션" 으로 정의.
