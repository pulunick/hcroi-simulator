# HCROI & 인건비 시뮬레이터 — 사용 설명서

인사담당자를 위한 화면별 사용법입니다. 산식과 가정의 근거는 [spec.md](spec.md), 앱 안의 **산식·가이드** 화면에도 같은 내용이 있습니다.

> **현재 단계: 프로토타입.** 로그인이 없고, 입력한 데이터는 **지금 쓰는 브라우저에만** 저장됩니다.
> 다른 PC·브라우저에서 보거나 백업·공유하려면 **데이터 관리 → 엑셀 내보내기**를 사용하세요.

## 0. 5분 시작하기

1. `대시보드` 를 열면 가상의 샘플(연간 2023·2024 + 2025년 분기 4개)이 들어 있습니다. 2025년 연간·반기는 분기에서 **자동 합산**된 것입니다(`합산` 표시). 화면 구성을 먼저 훑어보세요.
2. `데이터 관리` 에서 **샘플을 자사 실적으로 교체**합니다. (기간별 매출액·영업비용·총 인건비·임직원 수 4개 값이면 충분)
   결산서가 분기 단위라면 `엑셀 템플릿` 을 받아 **분기 × 3개년(12행)** 을 붙여 넣고 `엑셀 가져오기` 하는 것이 가장 빠릅니다.
   채워진 예시는 [samples/hcroi-sample-3y-quarterly.xlsx](samples/hcroi-sample-3y-quarterly.xlsx)(가상 회사, 분기 12행, 인건비 4항목·인원 구분 포함 — 연간은 합산으로 나옵니다) — 그대로 가져와서 화면을 익힌 뒤 값만 바꿔도 됩니다.
   결산서가 천원 단위·누계라면 `조직 정보` 시트에서 **금액 단위**와 **손익 입력 방식**만 맞추면 그대로 붙여 넣을 수 있습니다.
3. `대시보드` 로 돌아와 HCROI 와 등급, 기간별 추이를 확인합니다. 결산서에서 어떤 숫자를 옮기는지는 [8장](#8-결산서에서-값-옮기기) 을 보세요.
4. `시뮬레이터` 에서 내년 인원·임금·생산성 계획을 시나리오 A/B 로 넣고 HCROI 가 어떻게 바뀌는지 비교합니다.
5. 회의 전에 `엑셀 내보내기` 로 지표 표·시나리오 비교를 파일로 받아 두세요 (백업 겸 공유용).

## 1. 지표 한눈에 보기

| 지표                            | 뜻                                                                          | 산식                                   |
| ------------------------------- | --------------------------------------------------------------------------- | -------------------------------------- |
| **HCROI** (인적자본 투자수익률) | 인건비 1원을 투입해 회수한 금액(배). 1.0배 = 인건비만 겨우 회수(영업이익 0) | (영업이익 + 총 인건비) ÷ 총 인건비     |
| **HCVA** (인당 부가가치)        | 임직원 1인이 만든 "영업이익 + 인건비"                                       | (영업이익 + 총 인건비) ÷ 총 임직원 수  |
| 인당 매출액 / 인당 인건비       | 1인당 매출, 1인당 인건비                                                    | 매출액 ÷ 인원 / 총 인건비 ÷ 인원       |
| 영업이익률 / 매출 대비 인건비율 | 보조 비율                                                                   | 영업이익 ÷ 매출액 / 총 인건비 ÷ 매출액 |

**HCROI 등급** — 1.0배 미만 **위험**(영업손실) · 1.0–1.5배 **보통** · 1.5배 이상 **우수**. (3등급, 2026-09-03 확장 지침 반영)
화면의 모든 HCROI 는 **배수(예: 1.35배)** 로 표기하고 괄호에 % 환산(135%)을 함께 보여줍니다.

**단위 규칙** — 금액은 **원 단위 정수**로 입력하고(예: `14100000000`), 입력칸 아래에 선택한 표시 단위(기본 **천원**)로 환산한 힌트가 자동으로 뜹니다. 화면 표기는 `금액 표시 단위`(데이터 관리)로 바꿀 수 있고, 저장·계산·엑셀은 언제나 원 단위입니다. 비율은 `3` 을 넣으면 3% 입니다.

## 2. 대시보드 (`/`)

조회 기간의 HCROI 진단과 기간별(연간·반기·분기) 추이를 보는 화면입니다.

- **제목 옆 연필 아이콘**: 회사/조직 이름을 넣으면 제목이 "○○ HCROI 대시보드" 로 바뀝니다 (이 브라우저에만 저장, 엑셀 파일명·`조직 정보` 시트에도 사용). 엑셀로 내보냈다가 다시 가져오면 회사명도 같이 복원됩니다.
- **조회 기간** (우측 상단): 데이터 관리에 등록한 기간(연간·반기·분기·월)과 거기서 **합산된 상위 기간**(`· 합산`) 중 하나를 고릅니다. 지표 카드는 그 기간의 실적 그대로이며(연율화하지 않음),
  증감은 **달력상 같은 단위의 바로 앞 기간**(연간이면 전년, 2025년 1분기면 2024년 4분기)과 비교하고, 그 기간이 없으면 증감을 표시하지 않습니다. 반기·분기는 계절성이 있어 **전년 동기 대비**도 함께 보여 줍니다(전년 동기 데이터가 있을 때).
- **추이 단위** (차트 제목 옆, 유형이 둘 이상일 때): 추이 차트·표·인사이트는 한 단위만 봅니다 — 분기와 연간을 한 줄에 섞으면 비교가 안 되기 때문입니다. 기본은 조회 중인 기간의 단위입니다.
- **기준 데이터 카드** (좌측): 이 기간의 매출액 · 영업비용(또는 영업이익) · 총 인건비 · 총 임직원 수. 값을 고치면 **모든 지표가 즉시 재계산**되고 자동 저장됩니다.
  세부 내역을 쓰는 기간은 총 인건비 아래에 `세부 합계 · 미분류` 가 표시되며 총액은 여기서도 고칠 수 있습니다(세부 합계보다 작게 만들면 오류). 인원 구분을 쓰는 기간의 총 임직원 수는 자동 계산이라 읽기 전용입니다.
  **합산된 기간**(예: 분기 4개에서 나온 연간)은 전부 읽기 전용입니다. 하위 기간을 고치면 따라 바뀌고, 값을 직접 손보려면 `직접 입력으로 전환` 을 누르면 복사본이 생깁니다.
  직접 입력한 연간과 분기 합계가 다르면 **노란 경고**로 항목별 차이를 보여 주고 직접 입력한 값을 씁니다(결산 조정으로 확정치가 다른 경우는 그대로 두면 됩니다).
  - `비용 입력 방식` 토글로 **영업비용(인건비 포함)** 을 넣을지 **영업이익**을 넣을지 선택할 수 있습니다. 어느 쪽을 넣어도 다른 쪽은 자동 환산됩니다.
  - 총 인건비의 6개 세부 항목은 `세부 관리 →` (데이터 관리 화면)에서 편집합니다.
- **HCROI 히어로**: 배수 · % 환산 · 전기 대비 증감(배) · 등급 배지 · 한 줄 해석 · 실제 대입된 산식. 상단에 임직원 수 산정 기준(예: `기간 평균(FTE) · 정규직만`)이 함께 표시됩니다.
- **지표 타일**: HCVA, 인당 매출액, 인당 인건비, 영업이익, 영업이익률, 매출 대비 인건비율, 총 임직원 수 — 각각 전기 대비 증감을 색으로 표시(초록 = 개선, 빨강 = 악화).
- **기간별 HCROI 추이** (라인): 가로 기준선이 등급 경계(1.0 / 1.5). 점 위에 마우스를 올리면 값이 뜹니다.
- **인건비 vs 영업이익 비중** (누적 막대): 기간별로 총 인건비 + 비인건비 영업비용 + 영업이익 = 매출액 구성을 보여줍니다. 인건비 비중이 커지는데 영업이익이 얇아지는지 한눈에 봅니다.
- **추이 인사이트**: 규칙 기반 자동 진단 — N기(연간이면 N년) 연속 하락, 전기 대비 변동, **인건비 증가율 vs 부가가치 증가율** 비교.
- **기간별 지표 표**: 차트와 같은 숫자를 표로 제공(복사해서 보고서에 붙일 수 있음).
- 하단 **이 데이터로 시나리오 시뮬레이션 →** 버튼으로 시뮬레이터로 이동.

## 3. 시뮬레이터 (`/simulator`)

"내년에 인원 10% 늘리고 임금 5% 올리면 HCROI 가 어떻게 되나?"를 즉시 계산합니다.

- **기준 기간**: 시뮬레이션의 출발점(Baseline). 등록된 기간(연간·반기·분기) 중에서 고릅니다. 분기를 고르면 결과도 분기 금액입니다. 상단 요약에 HCROI · 매출 · 영업이익 · 총 인건비 · 비인건비 · 인원이 표시됩니다.
- **시나리오 A / B** (두 개를 동시에 비교):

  | 입력                                | 범위                                       | 뜻                                                                             |
  | ----------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------ |
  | 인원 변동                           | 비율 −30~+30 % 또는 **인원(명)** 직접 입력 | 적용 후 인원이 바로 아래 표시 (예: `적용 후 40명 (+4명)`)                      |
  | 평균 임금 인상률                    | −20~+20 %                                  | 인당 인건비에 곱해짐 (`9,400만원 → 9,870만원`)                                 |
  | 인당 생산성(인당 매출) 변화율       | −30~+30 %                                  | 인당 매출에 곱해짐                                                             |
  | 고급 가정 — 비인건비 중 변동비 비율 | 0~100 % (기본 0)                           | 매출이 늘 때 함께 늘어나는 비인건비의 비율. 0 이면 비인건비 전액을 고정비로 봄 |

  슬라이더를 끌거나 숫자를 직접 입력할 수 있고, `초기화` 로 변동 없음 상태로 돌립니다.

- **미니 결과**: 예상 HCROI(증감·등급), 예상 총 인건비, 예상 영업이익.
- **HCROI 유지 조건**: 기준 HCROI 를 지키려면 인당 생산성이 최소 몇 % 여야 하는지(손익분기 생산성), 임금은 최대 몇 % 까지 올릴 수 있는지(임금 인상 상한)를 자동 역산합니다.
- **시나리오 비교**: HCROI · 총 인건비 · 영업이익 · HCVA 4개 패널(기준 / A / B), 그 아래 9개 지표 비교표(증감 포함).
- **분석 인사이트** (시나리오별):
  - **악화 시** → 원인 분석(임금 > 생산성, 증원인데 생산성 정체, 감원 + 생산성 하락) → 구조적 개선책 ① 손익분기 생산성 ② 임금 인상 상한 ③ 필요한 고정비 절감액 ④ 인력 구조 조정
  - **개선 시** → 지속가능성 점검(감원 의존, 공격적 생산성 목표, 임금 삭감 부작용, **비인건비 전액 고정 가정에 의한 과대 추정** 경고)
  - **영업손실 전환 시** → 위험 경고

### 시뮬레이터 결과를 읽을 때 꼭 알아둘 가정

- 인원이 바뀌어도 **인당 인건비·인당 매출은 기준 기간 값을 유지**한다고 봅니다(신규 인원 램프업, 채용·퇴직 일회성 비용 미반영).
- **비인건비는 기본적으로 고정비**입니다. 그래서 증원 + 생산성 유지 시나리오는 영업이익이 크게 뛰어 보일 수 있습니다. 재료비·외주비처럼 매출 따라 늘어나는 비용이 있으면 `고급 가정 → 변동비 비율` 을 올려서 다시 보세요. 이 경우 인사이트에 과대 추정 경고가 함께 뜹니다.
- 세금·금융비용은 모델 밖입니다.

## 4. 데이터 관리 (`/data`)

- **기간별 데이터 표**: 기간 · 매출액 · 영업이익 · 총 인건비 · 인원 · HCROI(등급). **행을 클릭**하면 오른쪽에서 편집, 행 끝 휴지통 아이콘으로 삭제. 샘플 데이터에는 `샘플` 표시.
- **금액 표시 단위** (화면 상단): `자동(억·만 축약) · 원 · 천원 · 백만원 · 억원` 중에서 고릅니다. 기본은 **천원** 입니다.
  - **화면 표기만 바뀝니다.** 입력칸·저장값·엑셀 파일은 언제나 **원 단위 정수** 그대로입니다. 단위를 바꿔도 지표는 달라지지 않습니다.
  - 고정 단위를 고르면 표에서는 단위가 열 머리글로 올라가고(`매출액 (천원)`) 칸에는 숫자만 남습니다 — 결산서와 대조하기 쉽습니다.
  - 차트 축 눈금은 자릿수가 너무 길어지지 않도록 억·만 축약을 유지합니다.
  - 선택은 이 브라우저에 저장되고 모든 화면(대시보드·시뮬레이터·가이드)에 함께 적용됩니다.
- **임직원 수 산정 기준** (금액 단위 아래): 인원을 어떻게 센 숫자인지 밝히는 설정입니다. 기본은 **기간 평균(FTE) · 정규직만**.
  - `기간 평균(FTE)` / `기말 인원` — **표기용**입니다. 어느 쪽을 골라도 계산 결과는 바뀌지 않습니다(사용자가 넣은 숫자가 무엇인지 밝히는 용도).
  - `계약직·기간제 포함` · `파견·도급(소속 외) 포함` · `등기임원 포함` — 체크하면 **인원 구분을 입력한 연도**의 총원에 그 구분이 더해집니다.
  - 기준은 작업공간에 하나만 둡니다. 연도마다 다르면 추이 비교가 무의미해지기 때문입니다.
- **기간별 데이터 표**의 `합산` 행은 하위 기간에서 계산된 기간입니다(저장되지 않음, 삭제 불가). 클릭하면 값을 확인하고 `직접 입력으로 전환` 할 수 있습니다.
- **자동 합산 규칙**: 월 3개가 있으면 분기, 분기 2개면 반기, 반기 2개(=분기 4개)면 연간이 자동으로 생깁니다. **빠진 기간이 있으면 만들지 않습니다**(1~3분기만 있으면 연간 없음).
  금액은 합계, 임직원 수는 위 산정 기준의 방식대로(기간 평균 → 하위 기간 평균, 기말 → 마지막 기간 값) 모읍니다.
  직접 입력한 연간이 있고 분기가 3개뿐이면 **4분기 = 연간 − 1~3분기** 로 채워 줍니다(사업보고서에 4분기 값이 없을 때). `차감` 표시가 붙습니다.
- **기간 추가**: 연도를 적고 `연간 / 반기 / 분기 / 월` 을 고른 뒤(연간 외에는 순번까지) `추가`. 이미 직접 입력한 기간은 추가되지 않습니다. 합산으로만 있던 기간을 추가하면 그 기간은 직접 입력이 우선됩니다.
  새 기간은 **같은 단위의 가장 최근 기간 값**을 복사해 시작하니(분기를 추가하면 직전 분기 값) **반드시 자사 값으로 수정**하세요. 추가하면 다음 기간(4분기 → 이듬해 1분기)으로 자동으로 넘어갑니다.
  - 값은 **그 기간의 실적 그대로** 넣습니다. 분기라고 연간을 4로 나누거나, 연간이라고 분기를 4배 하지 마세요.
  - 결산이 없어 분기 실적이 없는 기간은 **반기로 추가**해 반기 실적을 넣으세요. 도구가 분기로 쪼개 추정하지 않습니다.
  - 한 해의 연간 레코드와 그 해의 분기 레코드를 함께 둘 수 있습니다(표에서는 분기 뒤에 연간이 옵니다).
- **편집 패널** (우측): 매출액 · 영업비용(인건비 포함) · 총 임직원 수 · 총 인건비 · 메모.
  - `초기화` 는 그 연도의 영업비용·인건비를 표준 기본값(매출 대비 인건비 22%, 영업이익률 8%)으로 되돌립니다. 매출액·인원은 유지.
  - `인원 구분으로 입력` 을 켜면 총 임직원 수를 **정규직 / 계약직·기간제 / 파견·도급(소속 외) / 등기임원** 으로 나눠 적을 수 있습니다.
    총원은 **정규직 + 위 산정 기준에서 "포함"으로 둔 구분**만 더해 자동 계산되고, 직접 고칠 수 없게 됩니다(대시보드에서도 읽기 전용).
    구분을 안 쓰면 종전처럼 총원을 직접 입력합니다.
  - `세부 내역으로 입력` 을 켜면 총 인건비를 **기본급 / 성과급·수당 / 퇴직급여 / 법정후생비 / 기타 복리후생비 / 교육훈련비** 6항목으로 나눠 입력합니다.
    **6항목을 다 채우지 않아도 됩니다** — 세부 합계가 총액보다 적으면 차액이 `미분류` 로 표시되고, 지표는 언제나 **총 인건비** 기준으로 계산됩니다. 회사에서 분리하지 않는 항목(예: 법정후생비·교육훈련비)은 비워 두세요.
    세부 합계가 총액보다 크면 붉게 경고합니다. `총액을 합계로` 는 총 인건비를 세부 합계에 맞추고, `기본 구성비로 재분배` 는 총액을 표준 구성비(62/14/8/9/5/2%)로 나눠 줍니다.
  - 입력값이 이상하면(음수, 인건비 > 영업비용 등) 경고가 뜹니다. 변경은 자동 저장.
- **엑셀 내보내기** (`hcroi-YYYY-MM-DD.xlsx`, 회사명을 넣었으면 `hcroi-회사명-YYYY-MM-DD.xlsx`): 시트 5개 — ① `지표 요약`(기간별 HCROI·HCVA 등 계산 결과, 합산 기간은 `(합산)` 표시) ② `입력 데이터`(입력값 원본, 그대로 다시 가져올 수 있음) ③ `시나리오 비교`(현재 시뮬레이터의 A/B 파라미터와 결과) ④ `조직 정보`(회사/조직 이름 · 임직원 수 산정 기준) ⑤ `산식·가정`. 보고서에 붙일 표는 ①③ 을 쓰세요. ①③ 은 스냅샷이라 가져오기 때 무시되고, **다시 읽는 시트는 ②④ 뿐**입니다.
- **엑셀 템플릿** (`hcroi-template.xlsx`): 샘플이 채워진 입력 양식. 1행 헤더·2행 설명은 그대로 두고 **3행부터** 자사 값을 넣으세요.
  - 시트는 **보호**되어 있습니다(비밀번호 없음). 머리글과 맨 끝 `검증` 열은 잠기고 입력 칸(300행)만 열려 있습니다. 행 추가·정렬·서식은 됩니다. 풀려면 검토 → 시트 보호 해제.
  - `기간` 칸은 **드롭다운**(연간·상반기·하반기·1~~4분기·1~~12월)에서 고릅니다. 연도·금액·인원 칸은 문자·음수를 넣으면 바로 막힙니다.
  - 맨 끝 **`검증` 열**은 수식으로 그 행을 검사합니다. 비어 있으면 정상, 무언가 적히면(예: `세부 합계>총 인건비`) 행이 붉게 칠해집니다. 붙여넣기는 유효성 검사를 건너뛰니 이 열을 꼭 확인하세요. 앱에 올릴 때 한 번 더 검사합니다.
  - `조직 정보` 시트의 **금액 단위**(원/천원/백만원): 결산서 단위 그대로 붙여 넣고 이 칸만 맞추세요. 앱이 원으로 환산합니다. 비우면 원.
  - `조직 정보` 시트의 **손익 입력 방식**(기간 실적/누계): 분기·반기 보고서의 누계 열을 그대로 붙였다면 `누계` 로 두세요. 같은 연도·단위 안에서 앞 순번을 빼서 기간 실적을 만듭니다(1분기는 그대로, 앞 순번이 없으면 오류). 인원은 누계가 아니므로 그대로 읽습니다.
  - 필수: 연도 · 매출액(원) · 총 임직원 수(명) · 총 인건비(원). **영업비용 또는 영업이익 중 하나**만 있으면 됩니다.
  - `기간` 열은 선택입니다. 비우면 **연간**, `1분기`~~`4분기` / `상반기`·`하반기` / `1월`~~`12월` 을 적으면 그 기간이 됩니다(`Q1`, `H1`, `M3` 표기도 읽습니다). 기간 열이 없는 옛 파일은 전부 연간으로 읽힙니다.
  - **연간과 분기를 둘 다 적을 필요가 없습니다.** 분기 4개만 넣으면 연간·반기는 앱이 합산합니다. 둘 다 적으면 직접 적은 연간이 우선되고 합계와 다르면 경고가 뜹니다.
  - 금액은 `조직 정보` 시트의 단위대로(기본 원, `14,100,000,000` 처럼 콤마가 있어도 됨). "141억" 같은 문자 표기는 읽지 못합니다.
  - 인건비 세부 항목은 일부만 채워도 됩니다. 총 인건비 칸을 비우면 세부 합계가 총액이 되고, 총액을 함께 적었는데 세부 합계가 그보다 **적으면** 차액을 미분류로 두고 경고만 표시합니다. 세부 합계가 총액보다 **크면** 오류로 잡습니다.
  - 인원 구분(정규직·계약직·파견·등기임원) 열도 선택입니다. 채우면 총 임직원 수 칸은 비워도 됩니다(산정 기준을 적용한 합계로 채웁니다).
    총원 칸과 합계가 다르면 **합계를 쓰고 경고**합니다.
  - `조직 정보` 시트의 **`회사/조직 이름` 옆 칸(B1)** 에 회사명을 적으면 가져올 때 대시보드 제목까지 함께 설정됩니다. 비워 두면 기본 제목을 씁니다.
- **엑셀 가져오기**: 파일을 올리면 바로 반영되지 않고 **미리보기**가 먼저 뜹니다. 행마다 `신규` / `덮어씀` / `건너뜀` / `오류` 와 사유가 표시됩니다.
  - `기존 기간 덮어쓰기`(기본 켬)를 끄면 이미 있는 기간(같은 연도·단위·순번)은 건드리지 않습니다. 같은 해라도 연간과 분기는 서로 다른 기간입니다.
  - 파일의 임직원 수 산정 기준이 지금 설정과 다르면 `임직원 수 산정 기준도 "…" 으로` 체크박스가 뜹니다(기본 켬).
    기준 행이 없는 옛 파일은 현재 설정을 그대로 둡니다.
  - 파일의 `조직 정보` 회사명이 지금 제목과 다르면 `대시보드 제목도 "○○" 으로` 체크박스가 함께 뜹니다(기본 켬). 끄면 데이터만 반영합니다. `조직 정보` 시트가 아예 없는 파일은 제목을 건드리지 않습니다.
  - 오류 행이 있으면 반영이 막힙니다. 파일을 고쳐 다시 올리거나 `오류 행 건너뛰고 반영` 을 켜세요.
  - `반영` 직전 상태가 자동 보관되어 **되돌리기** 버튼으로 한 번 되돌릴 수 있습니다(새로고침 후에도 유지).
- **고급 (JSON)**: 개발·백업용 원본 형식. JSON 가져오기는 미리보기 없이 전체를 덮어씁니다. 일반 사용자는 엑셀을 쓰세요.
- **샘플로 초기화** / **전체 삭제**: 확인 후 실행. 되돌릴 수 없으니 먼저 엑셀로 내보내 두세요.

## 5. 산식·가이드 (`/guide`)

핵심 수식 4개, 등급 기준, 시뮬레이션 가정 6단계, 표준 레퍼런스 기본값을 앱 안에서 바로 확인합니다. 경영진 설명용으로 이 화면을 함께 띄워두면 좋습니다.

## 6. 자주 묻는 질문

- **HCROI 가 % 로 나오길 기대했는데요.** 배수 옆 괄호가 % 환산입니다(1.25배 = 125%). 요구사항의 "HCROI(%)" 를 배수 × 100 으로 해석했습니다.
- **영업이익이 아니라 영업비용밖에 모릅니다.** 대시보드 `비용 입력 방식` 을 영업비용으로 두고 입력하면 영업이익은 자동 계산됩니다. 반대도 가능합니다.
- **증원했더니 영업이익이 3배가 됐어요. 맞나요?** 비인건비를 전액 고정비로 두는 기본 가정 때문입니다. 3장 "가정" 항목을 보고 변동비 비율을 조정하세요.
- **데이터가 사라졌어요.** 브라우저 데이터(사이트 데이터/캐시)를 지웠거나 다른 브라우저·시크릿 창을 연 경우입니다. 엑셀(또는 JSON)로 내보낸 파일이 있으면 가져오기로 복구할 수 있습니다.
- **파견 인력도 인원에 넣어야 하나요?** 넣을 수는 있지만 권하지 않습니다. 파견·도급 비용은 인건비가 아니라 지급수수료로 잡히는 경우가 많아서,
  총원에만 더하면 HCVA·인당 인건비가 실제보다 낮게 나옵니다. 넣으실 거면 인건비에도 해당 비용을 포함하세요.
- **금액을 천원 단위로 보고 싶어요.** 데이터 관리 화면 위쪽의 `금액 표시 단위` 를 바꾸세요(기본 천원). 화면 표기만 바뀌고 입력·저장·엑셀은 원 단위 그대로입니다.
- **엑셀도 천원으로 받을 수 있나요?** 내보내기는 원 단위 고정입니다. 대신 **가져오기**는 `조직 정보` 시트의 `금액 단위` 칸을 천원으로 두면 천원 값을 그대로 읽습니다. 파일이 자기 단위를 갖고 다니므로 1000배 차이가 섞이지 않습니다.
- **분기를 넣었는데 연간이 왜 안 보이나요?** 분기 4개가 다 있어야 연간이 합산됩니다. 1~3분기만 있으면 연간을 만들지 않습니다(추정하지 않음). 사업보고서로 연간을 직접 넣으면 4분기가 `차감` 으로 채워집니다.
- **월 12개를 넣었는데 분기·연간 인원이 이상해요.** 인원은 데이터 관리의 `임직원 수 산정 기준` 방식대로 모읍니다. 기간 평균이면 월 인원의 평균(반올림), 기말이면 마지막 달 값입니다. 월말 인원만 갖고 있으면 그대로 넣고 기준을 `기간 평균` 으로 두면 분기·연간 평균이 나옵니다.
- **엑셀을 올렸는데 "필수 열을 찾지 못했습니다" 라고 나와요.** 1행 헤더가 템플릿과 달라서입니다. `엑셀 템플릿` 을 받아 그 양식에 값을 붙여 넣으세요(헤더의 단위·별표·공백 차이는 무시됩니다).
- **분기 데이터가 없는 분기는 어떻게 하나요?** 그 구간은 **반기**로 추가해 반기 실적을 넣으세요. 도구는 반기 값을 분기로 쪼개 추정하지 않습니다. 추이는 단위별로 따로 보이니 분기 추이에는 그 구간이 비고, 반기 추이에는 들어갑니다.
- **분기 HCVA 가 연간의 1/4 인데 정상인가요?** 정상입니다. HCVA·인당 매출·영업이익은 그 기간의 금액이라 분기는 연간의 약 1/4 입니다. HCROI 는 같은 기간의 비율이라 분기와 연간을 바로 비교할 수 있습니다.
- **엑셀 파일을 다른 사람이 수정해서 다시 올려도 되나요?** 됩니다. `입력 데이터`·`조직 정보` 시트만 읽고, 기간(연도·단위·순번)이 같으면 덮어씁니다. 미리보기에서 무엇이 바뀌는지 확인한 뒤 반영하세요.
- **여러 명이 같이 볼 수 있나요?** 프로토타입에서는 엑셀 파일을 주고받는 방식입니다. 로그인·조직 공유(DB)는 다음 단계 항목입니다.
- **부서별·다년 예측·PDF 는요?** 다음 단계(Phase 2) 후보입니다 — [spec.md §9](spec.md).

| 손익분기 생산성 · 임금 인상 상한 역산                                                                                | PDF 리포트                                              |
| 인건비 세부 항목(일부만 입력 가능), 임직원 수 산정 기준·인원 구분, 금액 표시 단위                                    | 부서(본부–팀)별 분해 · 동종업계 비교 · 다년(3~5년) 예측 |
| 엑셀 내보내기/템플릿(드롭다운·유효성·검증 열·보호)/가져오기(단위·누계 환산, 미리보기·되돌리기), JSON 백업            | 결산서 PDF 자동 읽기                                    |

## 8. 결산서에서 값 옮기기

분기 결산서(또는 DART 분기·반기보고서)에서 기간마다 **4개 값**만 옮기면 됩니다. 계정 이름은 회사마다 다르니 아래는 출발점이고, 한 번 정한 기준은 모든 기간에 똑같이 적용하세요.

| 입력 칸                | 결산서에서 찾는 곳                                                        | 주의                                                                                                    |
| ---------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 매출액                 | 손익계산서 `매출액`(또는 `영업수익`)                                      | 누계가 아니라 **그 분기만**의 값. 분기보고서는 "3개월" 열을 쓰세요                                      |
| 영업비용 또는 영업이익 | 손익계산서 `영업이익`(가장 간단) — 영업비용은 `매출원가 + 판매비와관리비` | 둘 중 하나만 넣으면 됩니다. 영업외손익·세금은 넣지 않습니다                                             |
| 총 인건비              | 주석의 `비용의 성격별 분류` 중 급여 · 퇴직급여 · 복리후생비 합계          | 매출원가에 들어간 인건비까지 포함해야 합니다(판관비만 쓰면 제조·개발 인력이 빠짐). 4항목만 있으면 4항목 |
| 총 임직원 수           | 인사 시스템의 **기간 평균 인원**(없으면 `직원 등 현황` 표의 합계)         | 계약직·파견·등기임원 포함 여부는 `임직원 수 산정 기준` 설정과 맞추세요                                  |

- 결산서 단위(`단위: 천원` / `백만원`)를 확인하고 **원 단위로 환산**해 넣습니다. 엑셀 템플릿도 원 단위입니다.
- 결산서 PDF 를 도구가 직접 읽지는 않습니다. 표 정렬이 깨져 숫자가 다른 행에 붙는 경우가 있어 사람이 옮기는 편이 정확합니다.
- 동종업계 비교용으로 다른 회사 값을 넣을 때도 같은 기준(같은 계정, 같은 기간, 같은 인원 기준)으로 맞추세요. 기준이 다르면 비교가 무의미합니다.
