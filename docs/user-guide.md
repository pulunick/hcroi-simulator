# HCROI 시뮬레이터 사용 설명서

## 1. 이 도구로 무엇을 하나

기간별로 숫자 네 개만 넣으면 인적자본 지표가 바로 나옵니다.
매출액, 영업비용(또는 영업이익), 총 인건비, 총 임직원 수입니다.
인건비 1원이 얼마를 벌어 왔는지(HCROI)와 등급, 기간별 추이를 보여 줍니다.

**알아 두세요**

- 로그인도 계정도 없습니다. 열면 바로 씁니다.
- 입력한 값은 **이 PC 의 브라우저에만** 저장됩니다. 서버로 가지 않습니다.
- 공개판은 몇 명이 어느 화면을 봤는지만 쿠키 없이 셉니다. 입력한 숫자·파일·회사 이름은 보내지 않습니다(설명은 화면 아래 개인정보 안내).
- 다른 PC 에서 보려면 **설정** 에서 백업 파일을 저장해 옮깁니다.
- 휴대폰에서도 열립니다. 표는 옆으로 밀어서 봅니다.
- HCROI 는 인적자본 투자수익률(Human Capital ROI)의 줄임말입니다.

## 2. 5분 만에 첫 결과 보기

처음 열면 가상 회사 샘플이 들어 있습니다. 샘플을 자사 숫자로 바꾸면 끝입니다.

**이렇게 하세요**

1. **대시보드** 를 열어 화면 구성을 훑어봅니다.
2. 위쪽 메뉴에서 **데이터** 를 누릅니다.
3. 결산서 PDF 가 있으면 **결산서 PDF 가져오기** 를 누릅니다.
4. PDF 가 없으면 **엑셀 템플릿** 을 받아 채운 뒤 **엑셀 가져오기** 를 누릅니다.
5. **대시보드** 로 돌아와 HCROI 와 등급을 확인합니다.
6. **시뮬레이터** 에서 내년 계획을 넣어 봅니다.
7. **리포트** 에서 A4 한 장을 인쇄하거나 PDF 로 저장합니다.

**알아 두세요**

- 제목 옆에 **샘플 데이터** 칩이 떠 있으면 아직 가상 회사 숫자입니다.
- 자사 숫자를 한 기간이라도 넣으면 칩이 사라집니다.
- 채워진 예시 파일이 필요하면 [samples/hcroi-sample-3y-quarterly.xlsx](samples/hcroi-sample-3y-quarterly.xlsx) 를 그대로 가져와 보세요.
- 가장 빠른 길은 [3. 결산서 PDF 로 넣기](#3-결산서-pdf-로-넣기) 입니다.

## 3. 결산서 PDF 로 넣기

DART 보고서 PDF 를 올리면 도구가 숫자를 찾아 줍니다. 확인만 하면 됩니다.

**준비물**

- DART 의 사업보고서, 반기보고서, 분기보고서 PDF.
- 글자를 드래그해 복사할 수 있는 파일이어야 합니다.
- 스캔한 이미지 PDF 는 읽지 못합니다.
- DART 는 금융감독원 전자공시시스템입니다. dart.fss.or.kr 에서 내려받습니다.

**이렇게 하세요**

1. **데이터** 화면에서 **결산서 PDF 가져오기** 를 누릅니다.
2. **PDF 선택 (여러 개 가능)** 으로 파일을 고릅니다.
3. 파일마다 카드가 뜹니다. 카드 위쪽 **재무제표** 에서 별도와 연결 중 하나를 고릅니다.
4. **손익 열** 에서 3개월과 누적 중 하나를 고릅니다.
5. **기간** 이 맞는지 봅니다. 표지에서 읽어 미리 채워 둡니다.
6. 표에서 매출액과 영업이익을 확인합니다. 틀리면 **직접 입력(원)** 칸에 적습니다.
7. **인건비 구성** 에서 합칠 항목을 체크합니다. 체크한 합이 총 인건비입니다.
8. **총 임직원 수** 를 확인합니다.
9. **미리보기로 보내기** 를 누릅니다.
10. 미리보기 표를 확인하고 **반영** 을 누릅니다.

**되돌리기**

- **반영** 직후에는 **데이터** 화면에 **되돌리기** 버튼이 생깁니다.
- 한 번 누르면 반영 직전으로 돌아갑니다. 새로고침해도 남아 있습니다.

**알아 두세요**

- 파일은 브라우저 안에서만 읽힙니다. 어디로도 보내지 않습니다.
- **확인 필요** 표시가 붙으면 기간을 꼭 직접 확인하세요.
- 기간을 못 읽은 파일은 기간을 고르기 전까지 미리보기로 갈 수 없습니다.
- 반기보고서의 3개월 열은 2분기, 누적 열은 상반기입니다. 열을 바꾸면 기간도 따라 바뀝니다.
- 결산서 인원은 기말 인원입니다. 평균 인원을 쓰려면 직접 적어 주세요.
- 카드에서 고른 별도·연결, 열, 인건비 항목은 **회사 이름별로 기억** 됩니다.
- 다음 분기 파일을 올리면 **이 회사의 저장된 설정 적용** 이라고 표시되며 그대로 적용됩니다.
- 파일이 여러 개면 **확인된 파일 모두 미리보기로** 로 한 번에 보냅니다.

**결산서에서 찾을 곳**

| 입력 칸      | 결산서에서 찾을 곳      | 주의                            |
| ------------ | ----------------------- | ------------------------------- |
| 매출액       | 손익계산서 매출액       | 누계 말고 그 기간만             |
| 영업이익     | 손익계산서 영업이익     | 영업비용 대신 이것만 넣어도 됨  |
| 총 인건비    | 주석 비용의 성격별 분류 | 매출원가 쪽 인건비도 포함       |
| 총 임직원 수 | 직원 등 현황 표의 합계  | 인사 시스템 평균 인원이 더 정확 |

## 4. 엑셀로 넣기

급여 대장이나 결산 자료가 엑셀이면 양식에 붙여 넣는 편이 빠릅니다.

**이렇게 하세요**

1. **데이터** 화면에서 **엑셀 템플릿** 을 누릅니다.
2. 받은 파일을 열고 입력 데이터 시트의 **3행부터** 값을 채웁니다.
3. 기간 칸은 드롭다운에서 고릅니다. 비우면 연간으로 읽습니다.
4. 결산서 단위가 천원이면 조직 정보 시트의 **금액 단위** 를 천원으로 바꿉니다.
5. 누계 값을 붙였다면 조직 정보 시트의 **손익 입력 방식** 을 누계로 바꿉니다.
6. 맨 끝 **검증** 열이 비어 있는지 확인하고 저장합니다.
7. **엑셀 가져오기** 를 눌러 파일을 올립니다.
8. 미리보기에서 신규와 덮어씀을 확인하고 **반영** 을 누릅니다.

**알아 두세요**

- 꼭 필요한 칸은 연도, 매출액, 총 인건비, 총 임직원 수입니다.
- 영업비용과 영업이익은 둘 중 하나만 있으면 됩니다.
- 금액은 원 단위 정수로 적습니다. 141억 같은 글자는 읽지 못합니다.
- 분기 4개만 넣어도 반기와 연간은 도구가 합산합니다.
- **기존 기간 덮어쓰기** 를 끄면 이미 있는 기간은 건드리지 않습니다.
- 오류 행이 있으면 반영이 막힙니다. 파일을 고치거나 **오류 행 건너뛰고 반영** 을 켜세요.
- 조직 정보 시트에 회사 이름을 적으면 가져올 때 화면 제목도 같이 바뀝니다.
- 반영 뒤 **되돌리기** 로 한 번 취소할 수 있습니다.
- **엑셀 내보내기** 는 지표 요약, 입력 데이터, 시나리오 비교, 동종업계, 조직 정보, 산식·가정 여섯 시트를 담습니다.
- 다시 읽어 들이는 시트는 입력 데이터와 동종업계, 조직 정보 세 개입니다.
- 동종업계 시트는 회사명마다 기간 행을 적습니다. 이름이 같은 회사는 시트 내용으로 바뀌고, 시트에 없는 회사는 그대로 남습니다.
- 동종업계를 건드리고 싶지 않으면 미리보기에서 **동종업계 시트도 반영** 을 끄세요.
- 동종업계 시트만 채워 올려도 됩니다. 입력 데이터 시트가 비어 있거나 아예 없어도 동종업계만 반영합니다.
- 동종업계 시트에만 오류 행이 있으면 **동종업계 시트도 반영** 을 끄고 자사 데이터만 먼저 넣을 수 있습니다.

## 5. 데이터 화면에서 직접 넣기

기간을 하나씩 만들고 오른쪽에서 숫자를 채우는 화면입니다.

**이렇게 하세요**

1. **데이터** 화면 오른쪽 위의 **기간 추가** 칸에 연도를 적습니다.
2. 옆에서 연간, 반기, 분기, 월 중 하나를 고릅니다.
3. 연간이 아니면 순번까지 고릅니다.
4. **추가** 를 누릅니다.
5. 왼쪽 표에서 그 행을 클릭합니다.
6. 오른쪽 편집 칸에 매출액, 영업비용, 총 임직원 수, 총 인건비를 적습니다.
7. 값은 자동 저장됩니다. 따로 저장 버튼이 없습니다.

**알아 두세요**

- 새 기간은 같은 단위의 직전 기간 값을 복사해서 시작합니다. 반드시 자사 값으로 고치세요.
- 값은 그 기간의 실적 그대로 넣습니다. 연간을 4로 나누지 마세요.
- 분기 자료가 없으면 반기로 추가하세요. 도구가 반기를 분기로 쪼개지 않습니다.
- 인원을 정규직과 계약직 등으로 나누려면 **인원 구분으로 입력** 을 켭니다.
- 인건비를 여섯 항목으로 나누려면 **세부 내역으로 입력** 을 켭니다. 일부만 채워도 됩니다.
- 행 끝의 휴지통 아이콘으로 기간을 지웁니다.

**표에 붙는 표시**

| 표시               | 뜻                                          |
| ------------------ | ------------------------------------------- |
| 합산               | 하위 기간에서 계산된 기간. 여기서는 못 고침 |
| 샘플               | 아직 가상 회사 숫자                         |
| 복사됨 · 확인 필요 | 직전 기간 값 그대로. 실적으로 바꾸세요      |
| 입력 오류          | 지표와 추이, 리포트에서 빠지는 기간         |

**자동 합산 규칙**

- 월 3개가 모이면 분기, 분기 2개면 반기, 분기 4개면 연간이 자동으로 생깁니다.
- 빠진 기간이 있으면 상위 기간을 만들지 않습니다.
- 연간을 직접 넣었고 분기가 3개뿐이면 4분기를 빼기로 채웁니다.
- 직접 넣은 연간과 분기 합계가 다르면 노란 경고가 뜨고 직접 넣은 값을 씁니다.
- 합산 기간은 읽기 전용입니다. 손보려면 **직접 입력으로 전환** 을 누르세요.
- 하위 기간에 오류가 있으면 합산을 만들지 않고 어느 기간 때문인지 알려 줍니다.

## 6. 대시보드 읽는 법

고른 기간의 HCROI 와 등급, 기간별 추이를 보는 화면입니다.

**이렇게 하세요**

1. 오른쪽 위 **조회 기간** 에서 볼 기간을 고릅니다.
2. 가운데 큰 숫자로 HCROI 배수와 등급을 봅니다.
3. 그 아래 타일에서 인당 지표와 영업이익을 봅니다.
4. 차트 제목 옆 **추이 단위** 로 연간과 분기 중 무엇으로 볼지 고릅니다.
5. **표시 범위** 로 최근 몇 년을 볼지 고릅니다.
6. 맨 아래 **이 데이터로 시나리오 시뮬레이션 →** 로 넘어갑니다.

**알아 두세요**

- 왼쪽 **기준 데이터** 칸에서 숫자를 바로 고칠 수 있습니다. 지표는 즉시 다시 계산됩니다.
- **비용 입력 방식** 을 눌러 영업비용 대신 영업이익을 넣을 수 있습니다.
- 증감은 바로 앞 기간과 비교합니다. 반기와 분기는 전년 같은 기간과도 비교해 줍니다.
- 추이에서 속 빈 점과 점선은 그 단위 자료가 없어 연간 값으로 대신 표시한 것입니다.
- 붉은 **입력 오류** 카드가 뜬 기간은 지표를 내지 않습니다. 데이터 화면에서 고치세요.
- 노란 **복사됨 · 확인 필요** 줄이 보이면 아직 실적이 아닙니다.
- 회사 이름은 화면 맨 위 **회사 이름 넣기** 를 눌러 적습니다.

## 7. 시뮬레이터로 내년 계획 비교하기

인원과 임금, 생산성을 바꾸면 HCROI 가 어떻게 되는지 보는 화면입니다.

**이렇게 하세요**

1. 오른쪽 위 **기준 기간** 에서 출발점이 될 기간을 고릅니다.
2. 왼쪽 시나리오 A 에서 **인원 변동** 을 조정합니다. 비율과 인원 수 중에 고를 수 있습니다.
3. **평균 임금 인상률** 을 조정합니다.
4. **인당 생산성(인당 매출) 변화율** 을 조정합니다.
5. 아래 예상 HCROI 와 예상 영업이익을 봅니다.
6. 오른쪽 시나리오 B 에도 다른 가정을 넣어 비교합니다.
7. 처음으로 돌리려면 **초기화** 를 누릅니다.

**알아 두세요**

- 아래 **HCROI 유지 조건** 이 필요한 생산성과 임금 상한을 알려 줍니다.
- 인원이 늘어도 인당 인건비와 인당 매출은 기준 기간 값 그대로라고 봅니다.
- 인건비 외 비용은 기본적으로 고정비로 봅니다. 그래서 증원 시나리오의 이익이 커 보일 수 있습니다.
- 재료비처럼 매출 따라 늘어나는 비용이 있으면 **고급 가정 — 비인건비 중 변동비 비율** 을 올리세요.
- 세금과 이자 비용은 계산에 넣지 않습니다.
- 아래 **분석 인사이트** 가 왜 나빠졌는지, 무엇을 바꾸면 되는지 짚어 줍니다.

## 8. 동종업계와 비교하기

상대 회사 숫자를 넣으면 같은 기간의 자사 지표를 업계 평균과 나란히 볼 수 있습니다.

**이렇게 하세요**

1. 위쪽 메뉴에서 **동종업계** 를 누릅니다.
2. **회사 이름** 칸에 상대 회사를 적고 **회사 추가** 를 누릅니다.
3. 회사 이름을 눌러 펼치고 **기간 추가** 에서 연도와 기간을 고른 뒤 **행 추가** 를 누릅니다.
4. 그 행에 매출액, 영업이익, 총 인건비, 임직원 수를 적습니다. 금액은 원 단위입니다.
5. 회사가 여러 곳이면 엑셀 템플릿의 **동종업계** 시트에 한꺼번에 적어 **엑셀 가져오기** 로 올립니다.
6. 화면 오른쪽 위 **비교 기간** 에서 볼 기간을 고릅니다.
7. 표에서 자사 행과 업계 평균 행을 견주고, 아래 막대에서 순위를 확인합니다.

**알아 두세요**

- 상대 회사 값은 사업보고서나 감사보고서에서 옮겨 적습니다. 인건비는 주석의 비용의 성격별 분류를 보세요.
- 업계 평균은 각 회사 지표의 단순 평균입니다. 매출과 인건비를 다 더해 다시 계산하지 않습니다.
- 자사는 평균에 넣지 않습니다. 순위에는 자사도 넣습니다.
- 큰 회사 한 곳에 평균이 끌릴 수 있어 **중앙값** 도 함께 보여 줍니다.
- **인건비율만 낮을수록 좋은 지표** 로 순위를 매깁니다. 나머지 다섯 지표는 높을수록 좋습니다.
- 그 기간 값이 없거나 입력 오류인 회사는 평균에서 빠집니다. 표 위에 몇 곳 기준인지 적어 둡니다.
- 한 번에 한 기간만 견줍니다. 기간 길이가 다른 값을 섞지 않기 위해서입니다.
- 상대가 분기만 넣었어도 분기 네 개가 모이면 연간으로 견줄 수 있습니다.
- 상대 회사 값도 이 PC 에만 저장되고, 백업 파일과 엑셀 내보내기에 함께 담깁니다.

## 9. 리포트 한 장 만들기

기간 하나를 A4 한 장짜리 경영진 보고서로 만드는 화면입니다.

**이렇게 하세요**

1. 위쪽 메뉴에서 **리포트** 를 누릅니다.
2. **조회 기간** 에서 보고할 기간을 고릅니다.
3. **작성자** 와 **소속** 을 적습니다.
4. **인쇄 / PDF 저장** 을 누릅니다.
5. 인쇄 대화상자에서 대상을 PDF 로 저장으로 고릅니다.

**알아 두세요**

- 한 장에 판단 문장, 핵심 지표 네 개, 추이, 시나리오 비교, 제안이 들어갑니다.
- 시나리오는 시뮬레이터에 넣어 둔 가정을 그대로 씁니다.
- 작성자와 소속은 이 PC 에 기억됩니다.
- 회사 이름이 비어 있으면 안내가 뜹니다. 비운 채로도 인쇄는 됩니다.
- 입력 오류가 있는 기간은 리포트를 만들지 않습니다.
- 인쇄물은 흑백에서도 읽히도록 선과 글자만으로 만들었습니다.

## 10. 설정과 백업

모든 화면에 함께 적용되는 값과 백업을 모아 둔 화면입니다.

**이렇게 하세요**

1. 위쪽 메뉴에서 **설정** 을 누릅니다.
2. **금액 표시 단위** 에서 화면에 보일 단위를 고릅니다. 기본은 천원입니다.
3. **임직원 수 산정 기준** 에서 인원을 어떻게 센 숫자인지 고릅니다.
4. **화면** 에서 밝게와 어둡게를 고릅니다. 기본은 기기 설정을 따릅니다.
5. **백업 파일 저장 (.json)** 을 눌러 파일을 받아 둡니다.
6. 복구할 때는 같은 화면의 **파일 열기** 로 그 파일을 엽니다.

**알아 두세요**

- 표시 단위를 바꿔도 저장값과 지표는 달라지지 않습니다. 보이는 모양만 바뀝니다.
- 산정 기준에서 계약직이나 파견을 포함으로 두면 인원 구분을 넣은 기간의 총원이 늘어납니다.
- 기준은 작업공간에 하나만 둡니다. 기간마다 다르면 추이 비교가 무의미해집니다.
- 화면 위쪽에 **백업 권장 →** 이 뜨면 백업한 지 오래됐다는 뜻입니다.
- 백업 파일에는 회사 이름, 모든 기간, 동종업계 회사, 시나리오, 이 화면의 설정이 담깁니다.
- 동종업계 기능이 생기기 전에 받아 둔 옛 백업 파일을 불러오면 동종업계 목록은 지금 것이 그대로 남고 그렇게 알려 줍니다.
- 맨 아래 **이 PC 의 데이터 지우기** 는 되돌릴 수 없습니다. 모든 기간과 동종업계 회사가 함께 지워지니 먼저 백업하세요.
- 브라우저 사이트 데이터를 지우면 입력한 값도 함께 사라집니다.

## 11. 숫자와 등급의 뜻

**지표**

| 지표               | 뜻                                | 산식                               |
| ------------------ | --------------------------------- | ---------------------------------- |
| HCROI              | 인건비 1원이 회수한 금액          | (영업이익 + 총 인건비) ÷ 총 인건비 |
| HCVA               | 1인이 만든 영업이익과 인건비의 합 | (영업이익 + 총 인건비) ÷ 인원      |
| 인당 매출액        | 1인이 올린 매출                   | 매출액 ÷ 인원                      |
| 인당 인건비        | 1인에게 쓴 인건비                 | 총 인건비 ÷ 인원                   |
| 영업이익률         | 매출 중 이익 비율                 | 영업이익 ÷ 매출액                  |
| 매출 대비 인건비율 | 매출 중 인건비 비율               | 총 인건비 ÷ 매출액                 |

HCVA 는 인당 부가가치(Human Capital Value Added)의 줄임말입니다.

**등급**

| HCROI         | 등급 | 뜻                     |
| ------------- | ---- | ---------------------- |
| 1.0배 미만    | 위험 | 영업손실 상태          |
| 1.0배 ~ 1.5배 | 보통 | 인건비를 회수하는 수준 |
| 1.5배 이상    | 우수 | 인건비 이상을 벌어들임 |

**표기 규칙**

- HCROI 는 배수로 적고 괄호에 퍼센트를 함께 보여 줍니다. 1.35배는 135% 입니다.
- 금액은 원 단위 정수로 넣습니다. 입력칸 아래에 선택한 단위로 환산한 힌트가 뜹니다.
- 비율은 3 이라고 적으면 3% 입니다.
- 산식의 근거는 [spec.md](spec.md) 와 앱의 **가이드 → 산식·가정** 에 있습니다.

## 12. 자주 묻는 질문

**HCROI 를 퍼센트로 보고 싶어요.**
배수 옆 괄호가 퍼센트 환산입니다. 1.25배는 125% 입니다.

**영업이익을 모르고 영업비용만 압니다.**
둘 중 하나만 넣으면 됩니다. 나머지는 자동으로 계산됩니다.

**증원했더니 영업이익이 크게 늘어요. 맞나요?**
인건비 외 비용을 고정비로 보기 때문입니다. 시뮬레이터의 변동비 비율을 올려서 다시 보세요.

**데이터가 사라졌어요.**
브라우저 데이터를 지웠거나 다른 브라우저를 연 경우입니다. 백업 파일이나 엑셀이 있으면 복구됩니다.

**분기를 넣었는데 연간이 안 보여요.**
분기 4개가 다 있어야 연간이 생깁니다. 모자란 분기는 추정하지 않습니다.

**분기 HCVA 가 연간의 4분의 1 인데 정상인가요?**
정상입니다. 금액 지표는 그 기간의 값입니다. HCROI 는 비율이라 바로 비교할 수 있습니다.

**파견 인력도 인원에 넣어야 하나요?**
권하지 않습니다. 파견 비용은 인건비로 잡히지 않는 경우가 많아 인당 지표가 낮게 나옵니다.

**엑셀을 올렸더니 필수 열을 찾지 못했다고 나와요.**
1행 머리글이 양식과 달라서입니다. **엑셀 템플릿** 을 받아 그 양식에 붙여 넣으세요.

**엑셀을 천원 단위로 넣어도 되나요?**
됩니다. 조직 정보 시트의 **금액 단위** 를 천원으로 두세요. 내보내기는 원 단위로 나갑니다.

**업계 평균은 어떻게 계산하나요?**
회사마다 지표를 먼저 내고 그 값을 단순 평균합니다. 매출과 인건비를 다 더해 다시 계산하지 않습니다. 자사는 평균에서 빼고, 큰 회사에 끌릴 수 있어 중앙값도 함께 보여 줍니다.

**여러 명이 같이 볼 수 있나요?**
지금은 엑셀이나 백업 파일을 주고받는 방식입니다. 공유 기능은 아직 없습니다.

**휴대폰에서도 되나요?**
됩니다. 화면이 한 줄로 쌓이고 표는 옆으로 밀어서 봅니다.

**어둡게 보고 싶어요.**
**설정 → 화면** 에서 어둡게로 고정합니다. 인쇄물은 항상 밝은 바탕입니다.
